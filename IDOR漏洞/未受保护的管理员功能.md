# 未受保护的管理员功能

来源：PortSwigger Web Security Academy  
靶场：Unprotected admin functionality（未受保护的管理员功能）

## 知识点

### 漏洞本质

管理后台**没有任何权限校验**——任何登录用户（甚至未登录）都能直接访问，而且路径还被泄露了。

### 路径如何泄露

管理后台路径被隐藏（无链接、无菜单），但总能通过某种方式泄露：

| 泄露途径 | 说明 |
|---|---|
| robots.txt | 根目录，可能写 `Disallow: /administrator-panel` |
| JS 文件 | 前端代码里硬编码路径 |
| HTML 注释 | 开发者留下的线索 |
| 扫描器 | ffuf / dirsearch 爆破 |
| Burp 站点地图 | 爬虫自动收集 |

## 通关过程

### 1. 发现路径

访问根目录的 `robots.txt`：

```
User-agent: *
Disallow: /administrator-panel
```

拿到隐藏路径 `/administrator-panel`。

### 2. 直接访问

```
GET /administrator-panel
```

没有任何鉴权 → 直接进入管理面板。

### 3. 完成任务

在管理面板找到删除用户功能（`/admin/delete?username=carlos`），删除 carlos。

## 易错点 / 踩坑

| 坑 | 原因 | 解决 |
|----|------|------|
| 只靠扫描器通过 | 字典不一定覆盖随机路径名 | 先手动看 robots.txt / JS，再上扫描器 |
| 以为每个网站都有 robots.txt | 很多网站没有 | 成本极低，顺手访问一次，万一有就白捡入口 |
| 扫出路径就完事 | 没理解漏洞本质 | 要知道是"无鉴权"导致，不只是"发现路径" |

## 防御建议

1. **管理后台必须做鉴权**，不能只靠隐藏路径。
2. 不要在 robots.txt / JS 里暴露敏感路径。
3. 管理操作记录日志、绑定管理员角色。

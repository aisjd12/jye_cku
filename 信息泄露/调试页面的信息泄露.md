知识点：
1. 什么是调试页面？

- **本质**：开发者为排查问题留下的内部调试入口，如 phpinfo() 页面、debug 路由、测试接口，上线时忘记移除，成为公开的信息泄露点。
- **常见形式**：/cgi-bin/phpinfo.php、/debug、/phpinfo.php、/info.php、/_debug 等。

2. 为什么调试页面危险？

- **phpinfo() 全量泄露**：PHP 版本、编译参数、已加载模块、所有环境变量、服务器配置一锅端。
- **环境变量是关键**：SECRET_KEY、数据库密码、云厂商密钥常被放在环境变量里，泄露即被拿走。
- **组合攻击**：泄露的框架版本可直接映射已知 CVE，缩短攻击链路。

3. 攻击者如何发现调试页面？

- **翻 HTML 源码注释**：注释里常挂着内部链接（`<!-- Debug: ... -->`）。
- **路径爆破**：字典扫常见调试路径。
- **读 JS/响应头**：JS 文件里可能引用内部 API 或调试接口。

4. 如何防御调试页面泄露？

- 生产环境彻底移除调试页面、关闭调试模式（debug=false）。
- 对 phpinfo() 类敏感页面做访问控制或直接删除。
- 敏感密钥用密钥管理系统（Vault/KMS）管理，不落到明文环境变量。
- 定期审查源码注释与路由，避免内部路径残留。

通关过程：
1：打开靶场首页，查看页面 HTML 源码
2：在源码底部发现注释，指向调试页面 /cgi-bin/phpinfo.php
3：直接访问该路径
4：页面为 phpinfo() 输出，在 Environment 部分找到 SECRET_KEY
5：提交 SECRET_KEY → 完成

## 核心概念速记

```text
命令注入 = 用户输入被拼接进系统命令
```

常见拼接方式：

```text
;
&&
||
|
$(命令)
`命令`
```

## 常用验证命令

```text
whoami
id
pwd
ls
sleep 10
```

## 防御红线

- 禁止把用户输入直接拼进 shell 命令
- 使用系统 API 代替 shell 命令
- 必要时使用参数化调用
- 输入只允许白名单
- 服务权限最小化
